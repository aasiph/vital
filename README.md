## Vue.js, Inertiajs, Tailwind and Laravel Starter Kit.

A starter kit with all the required technologies for web development.
Please note that vue framework uses composition api with typescript for source code.
Although not much packages are used but you can remove the packages which you dont require.

### Requirements

- [PHP Version 8.3+](https://www.php.net/)
- [Composer Version 2.2+](https://getcomposer.org/)
- [Node Version 18+ or 20+](https://nodejs.org/)

### Installation

```sh
git clone https://github.com/aasiph/vital.git yourappname
cd yourappname

composer install
npm install

php artisan migrate --seed

composer run dev
```
